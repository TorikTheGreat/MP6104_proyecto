\subsection{Subsistema decodificador}

El subsistema decodificador recibe el canal seleccionado del archivo en formato de modulación por impulsos codificados (PCM) de \SI{16}{bits} a $f_s = \SI{44.1}{\kilo\hertz}$ y los retardos configurados $t_0$ y $t_1$ en microsegundos, los cuales se convierten a muestras enteras mediante $d_b = \lfloor (t_b f_s + 5\times 10^5)/10^6 \rfloor$. A partir del mayor retardo se fija la longitud de ventana $L = K \max(d_0, d_1)$ con $K = 25$, segmentando la señal en $N_v = \lfloor N_{\mathrm{muestras}} / L \rfloor$ ventanas contiguas $v_k(n)$. La arquitectura completa del módulo se ilustra en la Figura~\ref{fig:diagrama_decodificador}.

En cada ventana $v_k(n)$ se calcula primero su valor eficaz $\mathrm{RMS}(v_k) = \sqrt{\frac{1}{L}\sum_{n=0}^{L-1} v_k^2(n)}$. Si $\mathrm{RMS}(v_k) \le 10^{-5}$, la ventana se declara silenciosa y se etiqueta inmediatamente como carente de eco ($\mathrm{SIN\_ECO} = -1$). En caso contrario, se normaliza mediante $\hat{v}_k(n) = v_k(n)\,\mathrm{RMS}_{\mathrm{ref}}/\mathrm{RMS}(v_k)$ con $\mathrm{RMS}_{\mathrm{ref}} = 1000$, eliminando cualquier dependencia respecto a la amplitud de entrada. Posteriormente, $\hat{v}_k(n)$ se rellena con ceros hasta la siguiente potencia de dos $N_{\mathrm{FFT}} = 2^{\lceil \log_2 L \rceil}$ y se evalúa la transformada rápida de Fourier (FFT) propia de base dos. Para prevenir singularidades logarítmicas en frecuencias nulas, cada magnitud espectral se acota inferiormente por $\epsilon = 10^{-12}$ antes de calcular $S_k(m) = \left(\ln \max(|X_k(m)|, \epsilon)\right)^2$ y aplicar la transformada inversa rápida de Fourier (IFFT) que entrega $|R_{cc}(n)|$.

Finalmente, el clasificador evalúa las magnitudes $r_0 = |R_{cc}(d_0)|$ y $r_1 = |R_{cc}(d_1)|$. Si $\max(r_0, r_1) < U_{\mathrm{eco}}$ con umbral $U_{\mathrm{eco}} = 0.70$, o si $r_0 = r_1$, la ventana individual se clasifica como $\mathrm{SIN\_ECO}$; de lo contrario, se asigna el bit $0$ cuando $r_0 > r_1$ y el bit $1$ cuando $r_1 > r_0$. A nivel de señal completa, si menos del \SI{25}{\percent} de las ventanas no silenciosas superan $U_{\mathrm{eco}}$, el archivo se reconoce como no codificado y se devuelve una secuencia vacía; en archivos codificados, se recortan las colas finales sin eco y se entregan los bits al intérprete de trama.
